K Radius Subarray Averages

For each index i, average the 2k + 1 numbers from i − k to i + k (integer division), or write -1 if that range runs off either end. Re-adding every window from scratch costs O(n·k). Instead, keep one window sum and slide it right: add the number that enters, subtract the number that leaves.
