Given an integer array `nums` of length `n ≥ 2`, a **split** at index `i` (where `0 ≤ i < n − 1`) divides it into a left part `nums[0..i]` and a non-empty right part `nums[i+1..n−1]`. A split is **valid** if the left part's sum is greater than or equal to the right part's sum.

Return the number of valid splits.
